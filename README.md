BadApple in console (Python + OpenCV)

What is needed for the work

1. Window (linux dont work)
2. Install Python3
3. Open cmd
4. Install OpenCV (command: pip install opencv-python)
5. Use the `cd` command to navigate to the directory where my repository is stored.
6. Use command "python BadApple.py"
7. Once you’ve finished writing, immediately set the console to full-screen mode.
8. And wish yourself a good viewing experience
